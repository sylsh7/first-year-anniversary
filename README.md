# Happy Anniversary

React + Vite + TypeScript 一周年纪念册。

## 本地启动

安装 Node.js 22 或更新版本。在项目目录打开终端，运行

```sh
npm install
npm run dev
```

打开终端显示的地址，默认是 `http://localhost:5173`。`npm run build` 会检查 TypeScript 并生成 `dist/`。

## 替换内容

编辑 `src/content.ts`，把照片放进 `public/photos/`。例如把礼物照片保存为 `gift.jpg`，再填写 `gift.image.src: '/photos/gift.jpg'` 和对应的 `alt`。填写 `gift.note: ''` 可隐藏留言。

- `cover` 配置第一页的纸张背景、原拍立得、独立蜡烛和拼贴贴纸。贴纸共用一张透明素材表，`titlePieces`、`stickers[].crop` 是 SVG 裁切视框。点亮后，点击拍立得进入第二页。
- `memories` 配置第二页的皱纸背景、透明木夹、红心拍立得边框、拼贴装饰、提示和照片。按 `photos` 顺序抽取，每张的 `src`、`alt`、`back` 为路径、图片描述和背面留言。左右摇动显影后，点照片旁的旋转图标读背面，再拖到绳上的空位。全部挂好后，右下角箭头才出现，点击进入日历。JPEG 是 HEIC 的网页副本，原文件保留在提供的目录。
- `calendar` 配置第 03 页的所有文案与素材。`initialMonth` 默认为 `2025-08`；`items` 使用 `YYYY-MM-DD` 日期，纸质月份标签、真实日历排列与红笔圈选自动生成。每条的 `text` 为正文，`image.src` 为照片路径，`image.alt` 为描述。现有条目未填写正文，保留空字符串；六张本地风景占位图可替换为真实 JPG / PNG，更新对应路径即可。最后一条 `camera: true`，只有点击相机顶部的快门才记为完成。前五条均点开、最后一条完成拍照后，右下角才显示下一页箭头。所有进度保留于当前打开的页面，重新加载重置。
- `sharedHours.date` 按 `dateReference` 指定城市填写，格式为 `YYYY-MM-DD`。当前使用温哥华日期。通话时刻用 `call.time` 填写（`HH:mm`），`call.reference` 使用 IANA 时区名称。当前设置为温哥华当地 `23:00`。滑块以一分钟为单位，用同一个时刻更新两地日期和时间。
- `letter` 的 `greeting`、`paragraphs` 和 `signature` 分别控制称呼、正文和落款。

翻页后回到顶部。「上一页」可回看已打开的内容和已解锁的页面，进度保留在当前浏览器会话中的这次打开，重新加载会回到封面。

第一页贴纸表使用内置 imagegen 清理外围背景，处理提示为保留原有文字、贴纸白边、纸边纹理、位置和比例，并输出透明背景。最终素材为 `public/photos/anniversary-sticker-sheet.png`。拍立得使用提供的原始文件，独立蜡烛使用去掉原有火焰的透明素材。

第二页复用第一页的米白皱纸。木夹去白底后用 SVG 外形裁切清理边缘。新贴纸表 `memory-sticker-sheet.png` 和红心边框使用内置 imagegen 清理背景；处理要求为保留原字样、纸底、纹理和红心，边框中央照片窗口及外围透明。`heart-polaroid-frame.svg` 收紧外轮廓与窗口；`memories.frame.window` 定义照片放置范围，照片以完整比例嵌入，不裁人物。操作提示直接显示「摇一摇」或「挂上去」，不再使用便签或过渡文案。


第二页的五张照片背面和重看预览均使用本地汉仪晨妹子W。字体来源为汉仪官方产品页 https://www.hanyi.com.cn/productdetail.php?id=772，当前文件用于这本私人周年相册。

本轮检查：在 1280 与 1440 像素电脑窗口检查构图，实际拖动完成五张照片的抽取、来回摇动、翻面与悬挂；检查预览翻面、Esc 关闭及焦点返回；进入日历后返回第二页，五张悬挂状态与箭头解锁保持。

第二页修复：照片窗口根据透明边框开口对齐，四边额外覆盖 2px，照片与边框共用容器。落点使用照片顶部中央，统一换算页面与舞台坐标；接收范围为左右 240px、下方 280px、上方 190px 的椭圆，并为已高亮目标保留 45% 的退出容差，排除已占位置。五张照片均使用已确认的提示：18px、300 字重、深棕色、↙ 箭头，距照片上沿 24px，随照片移动并限制在窗口内。显影时显示「摇一摇 ↙」，读过背面留言后显示「挂上去 ↙」，完成后消失。已用鼠标逐一完成五张显影、翻面和悬挂，验证日历解锁及返回保留状态。

悬挂判定修复：高亮和松手共用唯一目标，目标改变时同步绘制高亮；移除“最新目标”和“已绘制目标”之间的竞态。拖动与最新松手坐标都先换算到舞台本地 CSS 坐标，以照片顶部中央选择最近的空木夹。已有高亮时直接夹住；没有高亮且已满足条件时，用最新松手位置检查一次。已读照片在拿起时即检查目标，不再因移动不足 7px 导致高亮或吸附失败。显影和翻面条件未满足时不高亮。木夹下端对齐相纸顶部白边。

最终浏览器复核：五个木夹各完成从侧面、从下方、高亮退出边缘松手三轮，共 15 次成功，包含从下方只移动几像素的回归场景；每轮都能解锁下一页。未翻面时不显示高亮，浏览器没有报错。场景分别在 1280×900 与 1280×1000 窗口检查。

连续照片松手修复：在窗口捕获阶段统一处理 pointermove/pointerup/pointercancel，不再让 lostpointercapture 直接清除拖动。每次拖动保存照片编号、目标木夹、准备状态与捕获元素；松手先结束该次拖动，再更新已悬挂列表，避免旧照片迟到的事件干扰下一张。读过留言的记录使用同步引用，下一张相纸使用独立 DOM key。吸附仍由松手直接提交，没有点击确认步骤。

从重置状态实际连续完成两轮：第一轮背面朝上拖到绳上，第二轮翻回正面后拖到绳上；五张均一次拖放成功，特别检查第三、四、五张，松手后直接读取悬挂数量，不再发送额外点击。两轮均解锁日历，浏览器无错误或警告。

## 第三页更新

左侧是参考图提取的复古夹子、空白纸页和小票，下方露出粉色爱心邮票；右侧照片保留原比例，使用红色图钉与纸质白边。切换月份会轻轻翻起纸页。模拟拍照使用 Web Audio 合成短促机械声和一次轻闪，不请求摄像头或麦克风权限。系统开启减少动态效果时停用翻页、闪光与滑出动画。

素材制作记录与最终提示词见 `ASSET_NOTES.md`。

第三页提示位置已确认：夹子右侧、月份标签上方，17px 细字体。相机屏幕采用深灰绿色颗粒背景与四角取景框，快门只在屏幕内短暂闪白，之后完整显示照片；照片与相纸按原图比例排版。

## 背景音乐

使用提供的《玲子4.0》MP3，存放在 `public/audio/background-music.mp3`。`src/content.ts` 的 `music` 统一配置路径、音量（`volume: 0.2`）、淡入时间（`fadeInMs: 1800`）及按钮文案。第一次点亮蜡烛时开始播放，音量平滑淡入至 20%；整曲循环。音频元素放在整站根节点，翻页不重建，不从头播放。右上角按钮可暂停或从当前位置继续，继续时同样淡入。浏览器或文件加载暂时失败时，可用右上角继续按钮重试。
